A ZIP code radius search lists every ZIP code whose center lies within a set distance of a starting point. The tool above opens on ZIP 10001 in Midtown Manhattan with a 10-mile radius; type any five-digit ZIP or an address to start your own.

## How to find ZIP codes within a radius

<div class="steps">

1. Type a five-digit ZIP code in **Center ZIP code**. The place, state and county appear underneath so you can check it. To center on a street address, a city or a landmark instead, use **Or center on an address**.
2. Enter the radius, or press a preset from 5 to 100 miles. Switch to kilometers if you prefer.
3. Read the count of ZIP codes inside the radius, with the number of places and counties and the states they fall in.
4. Scroll the list, nearest first, or sort it by ZIP code. Each row gives the place name and the distance from the center.
5. Press **Copy ZIP list** for a comma-separated list you can paste into a form, an ad platform or a spreadsheet, or **Download CSV** for the full table with distances, counties and coordinates.
6. To test one ZIP code, type it in **Is this ZIP inside the radius?**

</div>

<Callout title="Adjusting on the map">
Drag the center point to move the search, or drag the white handle on the edge of the circle to change the radius. The list updates as you go. Dark dots are ZIP code centers inside the circle; light dots are just outside it.
</Callout>

## How many ZIP codes fall within a radius?

It depends on where you are. ZIP codes are drawn around mail delivery, so they are small and packed together in cities and large and sparse in the country. A 25-mile radius around Midtown Manhattan holds hundreds of ZIP codes; the same radius around Helena, Montana holds only a handful.

<ZipCountTable />

Doubling the radius roughly quadruples the area, but in a city it can do more than quadruple the ZIP count as the circle reaches dense suburbs, or far less if half the circle falls over water or mountains.

## How ZIP codes work

ZIP stands for Zone Improvement Plan. The US Postal Service introduced five-digit ZIP codes in 1963 to speed up mail sorting. A ZIP code is really a set of delivery routes rather than a neatly bounded area, which has a few practical effects:

- **Some ZIP codes are tiny or have no area at all.** Large buildings, universities, government agencies and post office box sections can have their own ZIP code.
- **Boundaries change.** The Postal Service adds and adjusts ZIP codes as routes change, so lists from different years can differ slightly.
- **The Census Bureau uses ZCTAs.** For statistics, the Census Bureau builds ZIP Code Tabulation Areas, which approximate ZIP codes as areas. They are close to, but not the same as, postal ZIP codes.

## How the radius search works

Each ZIP code in the list is represented by a single center point with a latitude and longitude. The tool measures the straight line distance from your center to each ZIP's point over the curved Earth, and includes the ZIP when that distance is within the radius.

That means:

- **A ZIP whose center is just outside the circle is left out,** even if some of its streets are inside. If edge cases matter, add a mile or two to the radius and check the extra ZIP codes by hand.
- **Distances are straight lines, not drives.** A ZIP 10 miles away across a river or a bay may be a much longer trip. For driving distances to a particular place, use the [distance between two addresses](/distance-between-two-addresses/) calculator.
- **Centering on a ZIP code uses the ZIP's center point,** which may be some way from your address in a large rural ZIP. Center on the exact address when precision matters.

The list covers about 41,000 US ZIP codes from the GeoNames postal code database, which is published under a Creative Commons Attribution license.
